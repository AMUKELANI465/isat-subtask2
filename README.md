# ISAT Subtask 2

## Number Converter

This is a C++ number converter program created for ISAT Subtask 2.

The program can convert:

1.  Decimal to Binary
2.  Binary to Decimal
3.  Decimal to Hexadecimal
4. Hexadecimal to Decimal

## Features

The program has a menu that allows the user to choose which conversion they want to use.

It also has a Demo option that converts a number from decimal to binary.

The Exit option closes the program.
